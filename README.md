# TrackFix

Free trackpad helper. Hold a key and slide one finger. Finger up scrolls up. Finger up zooms out, including in Blender.

The file you want on a Windows laptop is **TrackFix.exe**. Save it, then double-click it. Do not open it in an editor. Windows asks for permission. Choose **Yes**. Or right-click the file and choose **Run as administrator**.

## Windows

1. Download TrackFix.exe.
2. If the browser or an editor opens it, that is not the app. Save the file to a folder, then leave the editor.
3. Double-click TrackFix.exe in File Explorer.
4. Choose Yes when Windows asks to allow changes. If that prompt does not appear, right-click TrackFix.exe and choose Run as administrator.
5. If SmartScreen says Windows protected your PC, choose More info, then Run anyway.

Right Ctrl scrolls. Right Shift zooms. F8 orbits. Ctrl+Shift+F12 pauses.

## Mac

Unzip TrackFix-mac.zip. Control-click TrackFix and choose Open, then Open again. Allow it under Privacy and Security, Accessibility. Ctrl+Shift+Q quits.

## Linux

Unzip. In that folder run `chmod +x TrackFix && ./TrackFix`. Type y if it asks to read the trackpad. Press h for the guide. Press q to quit. Steam Deck: Desktop Mode, the x64 zip.

## Chromebook and Chrome

Unzip. Open `chrome://extensions`, turn on Developer mode, Load unpacked, and choose the TrackFix-chrome folder. This covers web pages, not Android apps.

iPad, iPhone, and Android cannot run a system-wide hook.
