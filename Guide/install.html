Practice Apps Install Updates Support

Every download includes this Guide folder: Practice, Apps, Install, Updates, and Support. Open Guide/index.html any time.

Windows

  1. On Windows, download TrackFix.exe from the GitHub repository. Save the file. Do not open it in an editor.
  2. Double-click TrackFix.exe. When Windows asks for permission, choose Yes. Or right-click the file and choose Run as administrator.
  3. If Windows says it protected your PC, choose More info, then Run anyway.
  4. The window can hide to the tray. The hotkeys stay on.
  5. Right-click the tray icon and choose Guide to open these pages again.
  6. Use the 64-bit file on a normal Windows 10 or 11 laptop, the ARM file on a Snapdragon or Surface, and the 32-bit file only if the others refuse to open.

Mac

  1. Unzip. Control-click TrackFix and choose Open, then Open again.
  2. System Settings, Privacy & Security, Accessibility: turn TrackFix on, then open it again.
  3. The first launch opens this guide. Right Ctrl scrolls, Right Shift zooms, F8 orbits.
  4. Ctrl+Shift+Q quits. One download covers Apple silicon and Intel.

Linux

  1. Unzip. In a terminal in that folder, run chmod +x TrackFix && ./TrackFix
  2. If it asks to allow the trackpad, type y and your password. Leave the window open.
  3. Press h in that window to open this guide. Press q to quit.
  4. Use the x64 zip on most laptops and the ARM zip on Asahi, Pinebook, and other ARM64 machines. Steam Deck: Desktop Mode, x64 zip.
  5. Do not use this file inside a Chromebook's Linux container.

Chromebook and Chrome

  1. Unzip. Open chrome://extensions and turn on Developer mode.
  2. Load unpacked and choose the TrackFix-chrome folder.
  3. Open the TrackFix icon. Practice, Apps, Install, Updates, and Support are listed there.
  4. If the keyboard has no Right Ctrl, choose Chromebook keyboard.
  5. This changes web pages. It does not control Android apps.

iPad, iPhone, and Android

Those systems do not allow a trackpad hook. There is no install file. The practice page in the browser only affects that page.
