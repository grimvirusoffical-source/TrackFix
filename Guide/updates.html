How to replace a copy

Windows. Quit from the tray icon. Exit, don't only hide it. Replace TrackFix.exe. Keys stay in AppData\TrackFix.

Mac. Quit with Ctrl+Shift+Q. Replace TrackFix.app. Allow Accessibility again if macOS asks.

Linux. Press q. Replace the TrackFix file. Run chmod +x on the new one.

Chrome. Replace the folder, then on chrome://extensions click Reload.
